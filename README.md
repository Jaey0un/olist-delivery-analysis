# Olist 배송 지연 분석

브라질 이커머스 Olist의 2017년 1월–2018년 8월 주문 99,092건([공개 데이터](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce))으로 배송 지연을 어디서부터 조사할지 분석했습니다.<br>
정시 배송률은 93.2%였고, 리뷰 1–2점 비율은 정시 배송 주문 9.2%, 8일 이상 지연된 주문 79.3%였습니다.<br>
인계·배송 상태를 모두 확인할 수 있는 단일 판매자 지연 주문의 <strong>72.2%</strong>는 판매자가 운송사 인계 기한을 지켰습니다.<br>
이에 따라 운송 구간 조사와 함께, 인계가 반복적으로 늦은 판매자 70곳(P1, 인계 지연의 <strong>32.5%</strong>) 점검을 제안합니다.

## Problem

전체 배송 지연률만으로는 어느 구간과 판매자를 먼저 확인해야 할지 판단하기 어렵습니다. 지연률이 높아도 주문이 몇 건뿐인 판매자가 있고, 최종 배송 지연을 판매자의 인계 지연과 구분해야 하기 때문입니다.

이 분석에서는 세 가지 질문을 다뤘습니다.

- 주문부터 배송까지 어느 단계에서 지연 주문과 정시 주문의 차이가 큰가?
- 주문량을 고려해도 인계 지연이 반복되는 판매자는 누구인가?
- 배송 지연 정도에 따라 고객 리뷰는 어떻게 달라지는가?

## Findings

| 항목 | 결과 |
|---|---|
| 단계별 소요 시간 | 운송 구간(인계→고객 도착) 중앙값: 지연 주문 26.2일, 정시 주문 7.0일로 <strong>약 19일</strong> 차이. 인계 구간(승인→인계)은 3.1일 vs 1.8일로 약 1.3일 차이 |
| 인계 지연과 최종 지연 | 인계 기한을 넘긴 주문의 최종 지연률 21.2%, 지킨 주문 5.4%. 다만 지연 주문 6,517건 중 <strong>72.2%</strong>(4,708건)는 인계 기한을 지킨 주문 |
| 지역 조합 | 배송 지연률 SP→RJ 14.3%, SP→SP 4.7%. 인계 지연률은 9.5% vs 9.1%로 비슷 |
| 판매자 우선순위 | P1 70곳이 인계 지연 8,652건 중 2,815건, <strong>32.5%</strong>를 차지 |
| 고객 반응 | 리뷰 1–2점 비율: 정시 9.2% → 1–3일 지연 32.1% → 4–7일 67.7% → 8일 이상 79.3% |

72.2%는 인계와 최종 배송을 모두 평가할 수 있고 최종 배송이 지연된 단일 판매자 주문 6,517건 기준이며, 전체 배송 지연 주문은 6,531건입니다. 리뷰 비율과 단계별 시간은 해당 값이 유효한 주문만으로 계산해 표본이 서로 다릅니다.

## Approach

<strong>약속일 판정.</strong> 약속 배송일의 시각은 모두 자정(00:00)으로 기록되어 있습니다. 도착 시각과 그대로 비교하면 약속한 날 도착한 1,291건이 지연으로 잡히고, 정시율은 93.2%에서 91.9%로 내려갑니다. 그래서 날짜끼리만 비교했습니다.

<strong>판매자 우선순위.</strong> 판매자의 절반은 평가할 수 있는 주문이 7건 이하입니다. 지연률로 줄을 세우면 주문이 몇 건뿐인 판매자가 맨 위에 옵니다. 주문이 충분히 쌓인 판매자 중에서 인계 지연이 여러 달 반복되고, 전체 인계 지연에서 차지하는 몫이 크거나 지연 시간이 긴 곳을 P1으로 묶었습니다. 기준값을 바꾸면 후보 수가 얼마나 달라지는지는 [02 노트북](notebooks/02_fulfillment_eda.ipynb)에서 확인할 수 있습니다.

<strong>테이블 결합.</strong> 원본 주문 99,441건 중 상품 행이 2개 이상인 주문이 9,803건, 결제 행이 2개 이상인 주문이 2,961건, 리뷰가 2개 이상인 주문이 547건입니다. 그대로 조인하면 이런 주문이 여러 번 세어지므로, 상품과 결제는 주문 단위로 먼저 집계하고 리뷰는 주문마다 가장 최근에 답변된 리뷰 하나만 남긴 뒤 붙였습니다.

## Interpretation

인계 지연 여부만으로는 전체 배송 지연을 설명하기 어렵습니다. SP→RJ처럼 배송 지연률이 높은 지역 조합은 운송 기록을 먼저 확인하고, P1 판매자는 월별 추이와 고객 지역별 성과를 함께 살펴보는 것을 제안합니다. 8일 이상 지연된 주문은 리뷰 1–2점 비율이 높으므로, 이런 주문에 고객 안내가 어떻게 나갔는지도 점검이 필요합니다.

다만 데이터에는 운송사 식별 정보와 실제 이동 경로가 없고, 거리·상품·판매자 구성·약속 배송 기간을 통제하지 않았으므로 인과관계를 확정할 수 없습니다. 이 분석은 실제 운영에 적용한 결과가 아니며, 제안한 조치의 효과는 적용 후 지연률과 고객 반응으로 검증해야 합니다.
